# TôDuro— Controle Financeiro Pessoal

Aplicativo mobile de controle financeiro pessoal desenvolvido com React Native, com o objetivo de facilitar a organização das finanças por meio do registro de receitas e despesas, acompanhamento do saldo e consulta de movimentações financeiras.

O projeto está sendo desenvolvido como atividade acadêmica da disciplina de Desenvolvimento Mobile.

## Funcionalidades

- Cadastro de usuários e login.
- Visualização do dashboard financeiro.
- Cadastro de receitas e despesas.
- Listagem do histórico de movimentações.
- Edição e exclusão de movimentações.
- Consulta do saldo atual.
- Visualização do total de receitas e despesas.
- Classificação das movimentações por categoria.
- Consulta de cotação de moedas por meio de uma API pública.
